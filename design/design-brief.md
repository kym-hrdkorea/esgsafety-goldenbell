# 디자인 브리프 (Claude Design 전달용)

## 프로젝트
한국산업인력공단(HRDK) 내부 직원용 **안전·청렴 ON! 골든벨** 웹앱(2026-08-28 개명, 구명 "안전 골든벨 퀴즈 리그").
슬로건: **안전 이룸, 함께 해냄**

전 직원 약 1,800명이 6주간 매주 12문항을 푸는 사내 퀴즈 리그다.
개인·부서 순위와 포상이 걸려 있고, 문항당 45초 제한시간이 있다.

## 핵심 과제
직원들이 **"안전은 재미없고 나와 관계없다"** 고 느끼는 것이 이 캠페인의 출발점이다.
공공기관 시스템처럼 보이면 1주차에 이탈한다.
그래서 이 디자인은 **오락기 앞에 앉은 기분**을 목표로 한다.

---

## 비주얼 방향 — 아케이드 × 안전 × 골든벨

세 가지가 아주 잘 맞는다. 억지로 섞는 게 아니라 **원래 같은 그래픽 언어**를 쓴다.

| 요소 | 시각 자산 | 아케이드와의 접점 |
|---|---|---|
| **안전** | 안전 노랑, 검정 해저드 스트라이프, 안전모, 경고 표지 | 아케이드 캐비닛 측면 그래픽이 원래 이 언어다 |
| **골든벨** | 금색 종, 무대 스포트라이트, 긴장감 | 노랑에서 금색으로 자연스럽게 이어진다 |
| **아케이드** | 고대비, 두꺼운 외곽선, 하드 섀도, 스코어 카운터 | 진행률·타이머·순위와 **기능적으로 일치**한다 |

### 팔레트

| 역할 | 방향 | 근거 |
|---|---|---|
| 배경 | 딥 네이비 / 차콜 (순수 검정은 피함) | 아케이드 캐비닛 바디. 순수 검정은 대비가 과해 한국어 장문에 부담 |
| 주색 | **세이프티 옐로** | 안전모·경고표지의 색. 골든벨 금색과 연속됨 |
| 성취 강조 | **브라스 골드** | 골든벨의 종. 만점·1위·달성에만 사용 |
| 정답 | **세이프티 그린** | 안전보건표지의 안내색. 의미론적으로도 맞다 |
| 오답 | 세이프티 레드 (최소 사용) | 금지·경고색 |
| 패턴 | 45도 노랑/검정 해저드 스트라이프 | 타이머 임박, 섹션 구분, 헤더 액센트 |

### ★ 가장 중요한 제약 — 한국어 픽셀 폰트를 쓰지 않는다

아케이드는 픽셀 폰트를 부르지만, **한국어 픽셀·도트 폰트는 모바일 17px에서 가독성이 무너지고
웹폰트 용량이 2~5MB**다. 문항을 읽는 게 이 앱의 전부인데 본문이 안 읽히면 끝이다.

**해결 방식 — 역할을 나눈다.**
- 문항 본문 / 선택지 / 해설 → **시스템 한글 산세리프.** 크고 또렷하게
- 점수 / 타이머 / 진행률 / 순위 **숫자** → 등폭(tabular-nums) + 두꺼운 웨이트로 **아케이드 감각 담당**
- UI 프레임 → 두꺼운 외곽선, 하드 섀도(offset only, blur 없음), 각진 코너 또는 아주 작은 라운드

즉 **아케이드는 숫자와 테두리에서, 가독성은 한글 본문에서** 각각 확보한다.

### 아케이드 장치 (권장)

- **스코어 카운터** — 점수가 롤업되며 올라가는 연출
- **진행률** — 12칸 블록 인디케이터. 채워지는 방식 (막대보다 칸이 아케이드답다)
- **타이머** — 세그먼트 게이지가 줄어드는 방식. 10초 이하에서 해저드 스트라이프 + 미세 진동
- **정답 피드백** — 금색 종 아이콘 + 짧은 링(ring) 모션. 골든벨의 핵심 상징
- **만점(12/12)** — 종이 울리는 연출. 이 앱의 최고 보상 순간
- **버튼** — 하드 섀도 + 누를 때 translate로 눌리는 물리감

### 하지 말 것

| 금지 | 이유 |
|---|---|
| 한글 픽셀·도트 폰트 | 가독성 붕괴 |
| CRT 스캔라인 · 글리치 효과 | 한국어 장문 판독 저해 |
| 네온 글로우 남발 | 텍스트 대비 저하 |
| 코인 / 라이프 / `GAME OVER` 문구 | 아래 톤 가드레일 참조 |
| 사고 현장·부상 이미지 | 공포 유발 금지 |
| 유치한 캐릭터 | 아케이드는 레트로 그래픽으로 내고, 캐릭터로 내지 않는다 |

### 톤 가드레일 — 반드시 지킬 것

72문항 중 상당수가 **심정지·화재·응급처치** 문항이다.
심폐소생술 문항에서 시간이 초과됐을 때 `GAME OVER`나 코믹한 실패 연출이 붙으면 톤이 무너진다.

- 시간초과 문안은 `시간이 초과되었습니다`를 유지한다 (`copy.md`)
- 오답·시간초과 연출은 **짧고 담담하게.** 실패를 놀리지 않는다
- 아케이드 연출의 강도는 **정답·성취 쪽에 쏟는다.** 골든벨은 울리는 게 주인공이다

## 레이아웃

- **모바일 우선.** 데스크톱은 중앙 정렬 단일 컬럼(최대 640px)으로 확장
- 응시 화면은 **한 화면에 하나의 문항.** 답변 단계는 스크롤 없이 보이는 것이 목표
- 하단 고정 CTA (엄지 도달 범위), 터치 타겟 최소 48px
- 정오는 **색상만으로 전달하지 않는다.** 반드시 아이콘 병기

## 반드시 강하게 표현할 3요소

1. **진행률** — 12문항 중 몇 번째인지 항상 보이게
2. **남은 시간** — 45초. 10초 이하에서 색·패턴·크기 변화. 긴장감은 주되 공포는 아니게
3. **정오 피드백** — 제출 순간의 성취/아쉬움. 애니메이션 300ms 이내

## 제작 요청 화면 (우선순위)

1. **응시 — 답변 단계** (4지선다 기준)
2. **응시 — 해설 단계** (정답 / 오답 / 시간초과 3가지 상태 전부)
3. **대시보드** (내 현황 카드 + 순위 4종 탭 + 5행 표시 → 더보기 20행)
4. **홈** (내 요약 + 이번 주 회차 카드 + 지난 회차)
5. 회원가입 (사번 / 소속 / 부서 / 닉네임 / PIN 4자리)
6. 회차 결과 (12/12 만점 연출 포함)

## 문항 유형 4종 — 전부 시안 필요

| 유형 | 개수 | 요구사항 |
|---|---|---|
| 4지선다 | 60 | 선택지 카드 4개. 선택 상태가 확실히 구분 |
| OX | 32 | O / X 큰 버튼 2개. 화면 절반씩 차지해도 좋다 |
| 순서배열 | 3 | **탭하면 번호 배지가 붙는 방식.** 드래그 아님. 재탭 해제 + `다시 선택` |
| 단답 | 1 | 텍스트 입력 1줄. 키보드가 올라와도 문항이 보여야 함 |
