# Claude Design 전달 프롬프트

> 첨부: `design/design-brief.md`, `design/copy.md`, `design/screens.md`, `design/sample-items.md`

---

첨부한 4개 문서를 기준으로 모바일 우선 웹앱 UI 시안을 만들어 주세요.

한국산업인력공단 내부 직원 약 1,800명이 6주간 매주 참여하는 **안전 골든벨 퀴즈 리그**입니다.
슬로건은 "안전 이룸, 함께 해냄"입니다.

## 원하는 느낌 — 아케이드 × 안전 × 골든벨

직원들이 "안전은 재미없고 나와 관계없다"고 느끼는 문제를 풀기 위한 캠페인입니다.
공공기관 시스템처럼 보이면 1주차에 이탈합니다. **오락기 앞에 앉은 기분**을 목표로 해주세요.

세 요소가 원래 같은 그래픽 언어를 씁니다.
- **안전** = 세이프티 옐로, 검정 해저드 스트라이프, 경고 표지 → 아케이드 캐비닛 그래픽과 동일
- **골든벨** = 금색 종, 스포트라이트 → 노랑에서 금색으로 연속
- **아케이드** = 고대비, 두꺼운 외곽선, 하드 섀도, 스코어 카운터 → 진행률·타이머와 기능적으로 일치

배경은 딥 네이비/차콜(순수 검정 아님), 주색은 세이프티 옐로,
성취는 브라스 골드, 정답은 세이프티 그린으로 잡아 주세요.

## ★ 절대 조건 — 한국어 픽셀 폰트를 쓰지 마세요

아케이드라고 픽셀 폰트를 쓰면 실패합니다. 한국어 도트 폰트는 모바일 17px에서
가독성이 무너지고 웹폰트가 2~5MB입니다. 문항을 읽는 게 이 앱의 전부입니다.

**역할을 나눠 주세요.**
- 문항·선택지·해설 → 시스템 한글 산세리프, 크고 또렷하게
- 점수·타이머·진행률·순위 **숫자** → 등폭(tabular-nums) + 두꺼운 웨이트로 아케이드 감각 담당
- UI 프레임 → 두꺼운 외곽선, 하드 섀도(blur 없이 offset만), 각진 코너

즉 아케이드는 숫자와 테두리에서, 가독성은 한글 본문에서 확보합니다.

## 톤 가드레일

72문항 중 상당수가 심정지·화재·응급처치 문항입니다.
심폐소생술 문항에서 시간초과에 `GAME OVER` 같은 연출이 붙으면 톤이 무너집니다.

- 시간초과 문안은 `시간이 초과되었습니다` 그대로 사용
- 오답·시간초과 연출은 짧고 담담하게. 실패를 놀리지 않습니다
- 아케이드 연출은 **정답·성취 쪽에 쏟아 주세요.** 골든벨은 울리는 게 주인공입니다
- 코인·라이프 개념, CRT 스캔라인, 네온 글로우 남발, 유치한 캐릭터는 피해 주세요

## 우선 제작 순서

1. **응시 화면 — 답변 단계** (4지선다)
2. **응시 화면 — 해설 단계** (정답 / 오답 / 시간초과 3가지 상태 전부)
3. **대시보드** (내 현황 카드 + 순위 4종 탭 + 5행 표시/더보기 20행)
4. **홈**

## 반드시 지켜 주세요

- `design/copy.md`의 한국어 문안을 **그대로** 사용. lorem ipsum 금지
- `design/sample-items.md`의 **실제 문항 6개**로 렌더링해 레이아웃 검증
  특히 `2-04`(가장 긴 문항+선택지+해설), `7-03`(순서배열 5항목)이 깨지면 안 됩니다
- 진행률(12문항 중 n번째), 45초 카운트다운, 정오 피드백 — 이 3가지를 시각적으로 강하게
- 정오는 색상만이 아니라 **아이콘을 병기**
- 터치 타겟 최소 48px, 하단 고정 CTA
- 다크모드 별도 제작 불필요(기본이 어두운 배경), 브라우저 스토리지 사용 금지
