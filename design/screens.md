# 화면 목록 및 플로우

## 라우트
| 경로 | 화면 | 인증 |
|---|---|---|
| `/login` | 로그인 | - |
| `/signup` | 회원가입 | - |
| `/` | 홈(회차 목록) | 필요 |
| `/round/[no]/learn` | 사전학습 | 필요 |
| `/round/[no]/quiz` | 응시 (답변↔해설 2단계) | 필요 |
| `/round/[no]/result` | 회차 결과 | 필요 |
| `/round/[no]/review` | 복습(종료 회차) | 필요 |
| `/dashboard` | 순위 | 필요 |
| `/me` | 내 기록 | 필요 |
| `/admin` | 관리자 | 관리자 |

## 주 플로우
```
로그인/가입 → 홈
              ├─ [사전학습 보기] → 사전학습 → [이제 문제 풀기] ┐
              └─ [퀴즈 응시하기] ──────────────────────────┴→ 응시

응시: 문항 서빙 → 답변 → 제출 → 해설 → [다음 문제] → (12회) → 결과
결과 → [순위 보러 가기] → 대시보드
```

## 응시 화면 상태
| 상태 | 조건 | 표시 |
|---|---|---|
| answering | 미응답, 45초 이내 | 입력 UI + 카운트다운 |
| answering(임박) | 남은 10초 이하 | 타이머 강조 |
| explained(정답) | 정답 제출 | 정답 배너 + 해설 |
| explained(오답) | 오답 제출 | 오답 배너 + 정답 + 해설 |
| explained(초과) | 45초 초과 | 시간초과 배너 + 정답 + 해설 |
| completed | 12문항 종료 | 결과로 이동 |
| expired | 30분 방치 | 종료 안내 → 홈 |

## 네비게이션
하단 탭 3개: `홈` / `순위` / `내 기록`
응시 중에는 하단 탭을 숨기고 이탈 경고를 표시한다.
