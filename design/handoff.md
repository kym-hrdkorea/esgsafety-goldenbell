# Handoff: 안전 골든벨 퀴즈 리그 (HRDK)

> 경로 안내: 원본 핸드오프의 `specs/` 4개 문서는 이 폴더(`design/`)의 동명 파일과 동일본이다.
> `mocks/`와 `tokens.css`는 이 파일과 같은 폴더에 있다.

한국산업인력공단 내부 직원 약 1,800명이 6주간 매주 12문항을 푸는 **안전 골든벨 퀴즈 리그** 모바일 우선 웹앱.
슬로건: **안전 이룸, 함께 해냄**. 디자인 컨셉: **아케이드 × 안전 × 골든벨**.

## About the Design Files

`mocks/`의 파일들은 **HTML로 제작된 디자인 레퍼런스**입니다. 그대로 배포하는 프로덕션 코드가 아니라,
의도된 룩앤필과 인터랙션을 보여주는 프로토타입입니다. 과제는 이 디자인을 **대상 코드베이스의 기존
환경(React, Vue, Next.js 등)과 패턴으로 재구현**하는 것입니다. 환경이 아직 없다면 프로젝트에 가장
적합한 프레임워크를 선택해 구현하세요.

- 각 `.dc.html`은 브라우저에서 바로 열립니다 (`support.js`가 같은 폴더에 있어야 함).
- 목업 안의 **폰 프레임(노란 테두리 캐비닛)과 상단 "시안 N · 상태/문항 칩" 패널은 리뷰용 장치**입니다.
  구현 대상은 프레임 내부 390px 화면뿐입니다.
- `specs/`의 4개 문서(디자인 브리프, 확정 문안, 샘플 문항, 화면 목록)가 요구사항의 원본입니다.

## Fidelity

**High-fidelity.** 색·타이포·간격·상태·인터랙션이 확정값입니다. 코드베이스의 기존 라이브러리로
픽셀 수준 재현을 목표로 하세요. 모든 토큰은 `tokens.css`에 정리되어 있습니다.

## 절대 조건 (specs/design-brief.md 요약)

1. **한국어 문안은 `specs/copy.md` 그대로.** 임의 변경·추가 금지 (관리자 화면만 예외).
2. **한글 픽셀·도트 폰트 금지.** 아케이드 감각은 숫자(등폭+두꺼운 웨이트)와 테두리·하드 섀도가 담당.
3. **브라우저 스토리지(localStorage 등) 사용 금지.** 상태는 서버가 진실의 원천.
4. 터치 타겟 **최소 48px**, 하단 고정 CTA.
5. 정오 표시는 색상만이 아니라 **아이콘 병기** (✓ / ✕ / ◷).
6. 톤 가드레일: 시간초과는 `시간이 초과되었습니다` 그대로, `GAME OVER`·코인·라이프 금지.
   화려한 연출은 **정답·만점 쪽에만** (골든벨 링 모션).
7. 다크모드 별도 불필요 (기본이 어두운 테마).

### 응시 — 답변 단계 (가장 중요한 화면)

- **헤더** (`#161d33`, 하단 3px `#262f4d`): 회차 라벨(옐로 틱 4×15px + 13px/700) · 진행 `05 / 12`(Chakra Petch 22px 옐로 + 15px 딤). 아래 **12칸 진행 블록**(h 8px, gap 3px: 지난 문항 `#C9A227`, 현재 `#FFD400`+아웃라인, 남은 `#232b47`), **타이머 게이지**(h 18px, 테두리 2px, fill `#FFD400`, `width: (secs/45*100)%`를 1s linear로 감소, 위에 17px 간격 세로 눈금 오버레이) + 타이머 칩(min-width 78px, Chakra Petch 26px).
- **임박(≤10초)**: 게이지 fill → 노랑/검정 45° 해저드 스트라이프가 1s로 흐름, 테두리 옐로. 칩 → `#E23A2E` 배경 + 흰 글자 + `{n}초 남음` + 0.5s 미세 진동.
- **문항**: 유형 배지(골드 `#C9A227` bg, 11px/700) + 본문 22px/1.52/700 흰색, `word-break: keep-all`.
- **선택지 4종**:
  - 4지선다: 카드 min-h 56px, `#1b2239` bg + 3px `#3a4468` 테두리 + `4px 4px 0 #070a16` 섀도. 번호 배지 30px(Chakra Petch). **선택**: 옐로 bg + `#FFE873` 테두리 + translate(2,2) + 섀도 `2px 2px 0 #6B5200`, 글자 `#12172b` 700.
  - OX: 2열 그리드, h 150px, 글리프 Chakra Petch 64px. 선택 스타일 동일 문법.
  - 순서배열: `순서대로 눌러 주세요`(옐로 13px) + `다시 선택`(48px 아웃라인 버튼). 탭 → 배지에 순번, 재탭 → 해제. 드래그 없음.
  - 단답: input 56px, placeholder `정답을 입력하세요`. 키보드가 올라와도 문항이 보이도록 입력란은 문항 바로 아래.
- **하단 고정 CTA** `제출하기` 56px: 활성=옐로+`5px 5px 0 #6B5200`, 비활성=`#232b47`+딤 텍스트. 미선택 제출 시 CTA 위에 `! 답을 선택해 주세요`(옐로 13px).
- 답변 단계는 **스크롤 없이 한 화면**이 목표 (최장 문항 2-04로 검증됨).

### 응시 — 해설 단계

- 배너 3종 (등장 rise-in 250ms, 아이콘+제목 21px/800):
  - **정답**: 그린 패널(`#12261a`/`#24B24C`) + 골드 종 원형 아이콘에서 **링 2개 확산**(ring-out 0.8s/1.1s) + 종 스윙 + `+1 SCORE`(Chakra Petch 골드).
  - **오답**: 레드 패널, ✕ 아이콘. 애니메이션 없음. 담담하게.
  - **시간초과**: 뉴트럴 패널(`#1b2136`/`#5E6A8C`), 시계 아이콘. 중립 톤.
- `정답` 표기: 골드 4px 좌측 보더 블록. 선택지 리캡: 정답=그린+✓, 내 오답=레드+✕, 나머지 딤.
  순서배열은 정답 순서로 나열하고 위치 오답에 ✕, 아래 `내 답: 2 → 4 → 5 → 1 → 3`.
- `해설` 16px/1.65 `#C9D2E8`, `근거` 13~14px 딤. CTA: `다음 문제`, 12번째 문항에서 `결과 보기`.

## Interactions & Behavior

- **버튼 눌림(전역)**: `:active`에서 translate(3~4px,3~4px) + 섀도가 `1px 1px 0 rgba(0,0,0,0.6)`로 접힘. transition 없이 즉시 — 물리적인 눌림감.
- **타이머**: 45초. CSS width transition 1s linear로 매초 정확히 1/45씩 감소. 0초 도달 시 시간초과 해설 단계로.
- **점수 롤업**: 결과 화면에서 0부터 90ms 간격으로 +1.
- **네비게이션**: 하단 탭 3개(홈/순위/내 기록). **응시 중에는 탭 숨김** + 이탈 경고(`진행 중인 문제가 있습니다. 나가면 이어서 풀 수 없습니다.`).
- **애니메이션 예산**: 정오 피드백 300ms 이내 도착. 만점 연출만 예외적으로 길게(1.7s 링).
- 접기/더보기, 틀린 문제만 보기, 탭 전환은 즉시 상태 교체(전환 애니메이션 불필요).

## State Management (응시 플로우 기준)

```
quiz: { roundNo, currentIndex(0-11), phase: 'answering'|'explained',
        secondsLeft(45→0), selection: number|null | orderSeq: number[] | shortText: string,
        results: ('ok'|'wrong'|'timeout')[] }
```
- 제출 또는 45초 경과 → `explained`로 전환, 서버에 채점 기록. `다음 문제` → index+1, 타이머 리셋.
- 30분 방치 → 세션 만료 화면(`30분 이상 진행이 없어 이번 회차가 종료되었습니다.`).
- 재응시 불가, 순위는 3회 이상 참여부터 집계, 부서 순위는 참여자 3명 이상 부서만.
- **클라이언트 스토리지 금지** — 진행 상태 복원은 서버 세션으로.

## Design Tokens

### 폰트 로딩
- 한글: [Pretendard Variable](https://github.com/orioncactus/pretendard) — 목업은 jsDelivr dynamic-subset CSS 사용. 자체 호스팅 권장.
- 숫자: [Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch) 600/700 (라틴 전용, 숫자·타이머·순위에만).
