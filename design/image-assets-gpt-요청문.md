# GPT에 넣을 요청문

`design/image-assets.md`를 첨부하고 아래 요청문을 붙여 넣으면 된다.
**첫 요청문 하나**와, 이미지를 받은 뒤 쓰는 **반복 요청문**으로 나뉜다.

---

## 1. 첫 요청문 (파일 첨부와 함께 보낼 것)

```
첨부한 image-assets.md는 사내 웹앱 "HRDK 안전 골든벨 퀴즈 리그"의 이미지 자산
제작 명세서다. 이 명세대로 이미지를 순서대로 만들어 달라.

먼저 파일 전체를 읽고, 아래 규칙을 반드시 지켜라.

[규칙 1] 프롬프트 안의 대괄호 자리표시자를 직접 치환해라
각 항목의 프롬프트에는 [공통 스타일 문장], [공통 네거티브] 라고 적힌 자리가 있다.
이건 그대로 두면 안 되고, 문서 앞부분 "3. 공통 스타일 문장" 절에 있는 STYLE 블록과
NEGATIVE 블록의 실제 내용으로 바꿔 넣어야 한다. 각 항목에 추가 네거티브가 붙어
있으면(예: "+ no ribbon, no confetti") 공통 네거티브 뒤에 이어 붙여라.

[규칙 2] 한 번에 한 장씩 만들어라
여러 장을 한 이미지에 모아 그리지 마라. 순위 배지 3종처럼 세트로 보여야 하는 것도
반드시 따로따로 생성해야 크기와 정렬이 맞는다.

[규칙 3] 글자를 절대 넣지 마라
한글이든 영문이든 숫자든 이미지 안에 문자를 그리지 마라. 이 프로젝트는 모든 텍스트를
웹폰트로 따로 얹는다. 로고에도 글자를 넣지 말고 종 심볼만 만들어라.

[규칙 4] 색을 지켜라
프롬프트에 적힌 hex를 최대한 맞춰라. 특히 이 두 색의 역할을 절대 섞지 마라.
- 세이프티 옐로 #FFD400 = 조작·진행·주색
- 브라스 골드 #C9A227 = 성취 전용 (만점·1위·완주에만)
배경은 딥 네이비 #12172b 계열이고 순수 검정은 쓰지 않는다.

[규칙 5] 톤을 지켜라
이 앱의 문항 상당수가 심정지·화재·응급처치다. 아래는 전부 금지다.
- 유치한 캐릭터, 마스코트, 이모지
- 코인·라이프·GAME OVER 같은 게임 오버 모티프
- CRT 스캔라인, 네온 글로우, 렌즈 플레어
- 부상·피·사실적인 화염, 사이렌, 느낌표 강조
- 픽셀 아트, 도트 폰트
공공기관 캠페인이다. 화려하되 품위를 지켜야 한다.

[규칙 6] 스타일을 지켜라
플랫 벡터, 굵은 외곽선, 블러 없는 하드 섀도(오른쪽 아래 4px), 각진 코너,
1980년대 아케이드 캐비닛 측면 그래픽 × 한국 산업안전 표지의 조합이다.
그라데이션·3D 렌더·사진 실사는 쓰지 않는다.

작업 순서는 문서의 "생성 순서 권장"을 따라라. 즉 1-2(OG 이미지) → 1-1(앱 아이콘)
→ 2-2(회차 일러스트 6종) 순이다.

먼저 1-2 링크 공유 미리보기 이미지부터 시작해라. 생성 전에, 네가 실제로 사용할
최종 프롬프트 전문(자리표시자를 모두 치환한 상태)을 먼저 보여 주고, 내가 확인하면
생성해라.
```

## 2. 반복 요청문 (한 장씩 넘어갈 때)

```
좋다. 다음은 <항목 번호와 이름>이다.
같은 규칙(자리표시자 치환, 글자 없음, 색 역할 구분, 톤·스타일 유지)을 그대로 적용해라.
사용할 최종 프롬프트를 먼저 보여 주고, 확인하면 생성해라.
```

회차 일러스트 6종은 아래처럼 지시한다.

```
2-2 회차 일러스트다. 문서의 "공통 골격" 프롬프트에서 SUBJECT 문장만 표의 N회차
값으로 바꿔 6장을 만들 것이다. 지금은 1회차만 만들어라.
6장이 한 세트로 보여야 하니 골격 문장은 글자 하나도 바꾸지 마라.
1~5회차는 세이프티 옐로만 쓰고, 6회차만 브라스 골드를 쓴다.
```

## 3. 결과물을 받은 뒤 확인할 것

체크리스트대로 걸러야 한다. 생성 모델은 아래를 자주 어긴다.

- [ ] **글자가 들어갔는지** — 깨진 한글·의미 없는 영문이 섞이면 재생성한다
- [ ] **옐로와 골드가 섞였는지** — 성취 아닌 곳에 골드가 쓰였으면 재생성하거나 색 보정
- [ ] **소프트 그라데이션·글로우가 들어갔는지** — 하드 섀도 규칙 위반
- [ ] **KOSHA 공식 표지를 그대로 베꼈는지** — 안전보건표지는 규격이 법정이라 유사 도안은 오히려 혼란을 준다
- [ ] **작은 크기에서 읽히는지** — 앱 아이콘은 16px, 배지는 24px로 줄여 보고 판단한다
- [ ] **OG 이미지 중앙이 비어 있는지** — 글자 올릴 자리(가로 560px)가 확보돼야 한다

색이 어긋난 것은 재생성보다 편집기에서 보정하는 게 빠르다. 팔레트 값은 문서
"2. 색은 생성 후 보정한다" 표에 있다.

## 4. 받은 파일을 나에게 주면

`app/opengraph-image.png` 배치, `next/og`로 OG 이미지에 한글 제목 얹기,
회차 카드·사전학습 헤더에 일러스트 연결까지 이어서 처리하겠다.
