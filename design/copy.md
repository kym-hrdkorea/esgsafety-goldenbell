- 서비스명: **HRDK 안전 골든벨 퀴즈 리그**
- 슬로건: **안전 이룸, 함께 해냄**
- 로딩: `불러오는 중...`
- 일반 오류: `문제가 발생했습니다. 잠시 후 다시 시도해 주세요.`

## 회원가입
- 제목: `처음이신가요?`
- 부제: `사번과 소속을 입력하면 바로 시작할 수 있습니다.`
- 라벨: `사번` / `소속` / `부서` / `소속 · 부서`(통합 검색) / `닉네임` / `휴대폰 번호`
- 플레이스홀더: `사번을 입력하세요` / `소속을 선택하세요` / `부서를 선택하세요` / `순위표에 표시될 이름` / `휴대폰 번호를 입력하세요`
- 소속·부서 통합 검색 (기본 모드, 2026-07-31 확정):
  - 플레이스홀더: `소속이나 부서명으로 검색하세요`
  - 결과·확정 표기: `{소속} · {부서}`
  - 빈 결과: `검색 결과가 없습니다. 목록에서 직접 선택해 주세요.`
  - 폴백 링크: `목록에서 직접 선택` / 폴백에서 복귀: `소속이나 부서명으로 검색하세요`
  - 재선택 버튼: `다시 검색`
- 안내: `닉네임은 순위표에 표시되며, 가입 후 변경할 수 없습니다.`
- 안내: `휴대폰 번호 끝 4자리가 비밀번호로 설정됩니다.` (휴대폰 필드 아래, 2026-08-20 확정)
- 안내: `이름과 이메일은 수집하지 않습니다.` / `휴대폰 번호는 포상 지급 연락에만 사용합니다.`
- 버튼: `가입하고 시작하기`
- 오류: `이미 가입된 사번입니다. 로그인해 주세요.` / `이미 사용 중인 닉네임입니다.` / `올바른 휴대폰 번호를 입력해 주세요.` / `소속과 부서를 선택해 주세요.`
- 링크: `이미 가입하셨나요? 로그인`

## 로그인
- 제목: `HRDK 안전 골든벨 퀴즈 리그`
- 라벨: `사번` / `비밀번호 4자리`
- 안내: `휴대폰 번호 끝 4자리가 비밀번호로 설정됩니다.` (비밀번호 필드 아래, 2026-08-20 확정)
- 버튼: `로그인`
- 오류: `사번 또는 비밀번호가 올바르지 않습니다.`
- 잠금: `비밀번호를 5회 틀렸습니다. {n}분 후 다시 시도해 주세요.`
- 버튼(보조): `회원가입` — 로그인 버튼과 같은 56px 전폭, 남색 채움(`gb-cta-sub`)
- 링크: `비밀번호를 잊으셨나요?`

## 비밀번호 재설정
2단계로 보여주되 제출은 마지막에 1회. → addendum O항. 2026-08-20부터 새 비밀번호 직접 입력 대신 휴대폰 번호를 재입력받아 끝 4자리로 재설정한다(P항).
- 제목: `비밀번호를 잊으셨나요?`
- 부제: `가입할 때 입력한 정보로 확인한 뒤 휴대폰 번호로 비밀번호를 다시 설정합니다.`
- 라벨: `사번` / `닉네임` / `소속 · 부서` / `휴대폰 번호`
- 플레이스홀더: `사번을 입력하세요` / `가입할 때 정한 닉네임` / `소속이나 부서명으로 검색하세요` / `휴대폰 번호를 입력하세요`
- 안내: `휴대폰 번호 끝 4자리가 비밀번호로 설정됩니다.` (휴대폰 필드 아래)
- 결과·확정 표기: `{소속} · {부서}` / 재선택 버튼: `다시 검색`
- 빈 결과: `검색 결과가 없습니다.`
- 버튼: `다음`(1단계) / `비밀번호 변경하기`(2단계) / `이전`(2단계 보조)
- 오류: `입력한 정보가 일치하지 않습니다. 사번·닉네임·부서를 다시 확인해 주세요.`
- 오류: `올바른 휴대폰 번호를 입력해 주세요.` / `소속과 부서를 선택해 주세요.`
- 과다 요청: `요청이 많습니다. 잠시 후 다시 시도해 주세요.`
- 성공: `비밀번호가 변경되었습니다. 새 비밀번호로 로그인해 주세요.`
- 링크·버튼: `로그인으로 돌아가기`

## 응시 — 답변 단계
- 진행: `{현재} / 12`
- 타이머: `{초}초`
- 임박(10초 이하): `{초}초 남음`
- OX 버튼: `O` / `X`
- 순서배열 안내: `순서대로 눌러 주세요`
- 순서배열 초기화: `다시 선택`
- 단답 플레이스홀더: `정답을 입력하세요`
- 제출: `제출하기`
- 미선택: `답을 선택해 주세요`

## 응시 — 해설 단계

- 정답 표기: `정답: {정답}`
- 섹션: `해설` / `근거`
- 버튼: `다음 문제` / `결과 보기`(마지막)

## 회차 결과
- 제목: `{n}회차 결과`
- 점수: `{score} / 12`
- 정답률: `정답률 {pct}%`
- 포인트: `획득 포인트 {points}P`
- 순위: `이번 회차 {rank}위` (포인트 기준)
- 섹션: `문항별 결과`
- 토글: `틀린 문제만 보기`
- 버튼: `순위 보러 가기` / `홈으로`
- 격려(만점): `만점입니다. 다음 회차도 기대할게요.`
- 격려(일반): `틀린 문제의 해설을 한 번 더 읽어보세요.`

## 대시보드
- 제목: `순위`
- 내 현황: `내 순위` / `우리 부서 순위` (내 순위는 평균 포인트, 부서 순위는 종합점수 기준)
- 순위권 밖: `순위 집계 대상이 아닙니다`
- 최소 회차 안내: `3회 이상 참여하면 순위에 반영됩니다`
- 탭: `주간 우수자` / `전체 우수자` / `우수 부서` (포상 카테고리와 1:1 — 2026-08-25 개정)
- 확장: `더보기` / `접기`
- 표 헤더: `순위` `닉네임` `소속` `포인트` `평균 포인트` `부서` `종합점수`
- 부서 안내: `참여자 3명 이상인 부서만 표시됩니다`
- 부서 산식 안내: `종합점수 = 평균 포인트 50% + 참여율 50%`
- 부서 행 보조 표기: `평균 {avgPoints}P · 참여율 {pct}%` (참여율은 정수 반올림 표시)
- 갱신: `{시각} 기준`
- 빈 상태: `아직 참여 기록이 없습니다`
