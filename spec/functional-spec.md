# 기능 명세서

## 1. 범위

| 항목 | 내용 |
|---|---|
| 대상 | HRDK 전 직원 약 1,800명 (본부·부설기관·소속기관·국외 EPS 17개국) |
| 기간 | 6주 (시즌1 = 1~3회차 / 시즌2 = 4~6회차) |
| 개방 | 매주 월 00:00 ~ 금 23:59 (KST) |
| 문항 | 회차당 12문항, 총 72문항 |
| 소요 | 문항당 45초 / 회차당 약 9분 |
| 성격 | **2개월 한시 운영.** 종료 후 데이터 회수 → 프로젝트 삭제 |

## 2. 만들지 않는 것 (★ 중요)

명세에서 가장 중요한 절이다. 아래 기능은 **구현하지 않는다.**

- 이메일 인증, 소셜 로그인 (비밀번호 재설정은 **자율 재설정으로 구현한다** — addendum O항)
- 닉네임·소속·부서 **수정 기능** (가입 후 변경 불가)
- 재응시, 응시 취소, 답안 수정
- 회차 중단 후 이어하기 (30분 초과 시 그대로 종료)
- 문항 등록·수정·삭제 관리자 UI
- 알림 발송(이메일·SMS·푸시)
- 댓글, 게시판, 좋아요, 공유
- 개인 실명 노출 (닉네임만 사용)
- 다국어 (국외 EPS 포함 전원 한국어)
- 다크모드
- PWA·오프라인 지원
- 관리자용 순위 조작·점수 수동 부여

## 3. 화면 및 기능

### 3.1 회원가입 `/signup`
사번 → 소속·부서 통합 검색(소속명+부서명 매칭, 탭 1회 선택 — 2026-07-31 개선.
폴백: 소속(50개, optgroup) → 부서(연동) 2단 선택) → 닉네임 → 휴대폰 번호
- 비밀번호 입력란 없음 — 휴대폰 끝 4자리로 자동 설정(2026-08-20 P항).
  필드 아래 안내: "휴대폰 번호 끝 4자리가 비밀번호로 설정됩니다."
- 실시간 중복 검사: 사번, 닉네임
- 가입 완료 즉시 로그인 상태로 홈 이동

### 3.2 로그인 `/login`
사번 + 비밀번호 4자리(휴대폰 끝 4자리 — 필드 아래 안내 표시). 5회 실패 시 15분 잠금 안내.

### 3.3 홈 `/`
- 상단: 닉네임, 소속·부서, 누적 점수, 참여 회차 수
- 이번 주 회차 카드: 주제 + [사전학습 보기] + [퀴즈 응시하기]
  - 응시 완료 시 버튼이 [결과 보기]로 변경
- 이전 회차 목록: [복습하기] (점수 미반영)
- 아직 개방 안 된 회차: 잠금 표시

### 3.4 사전학습 `/round/[no]/learn`
- 마크다운 본문 렌더링, 이미지 중심, A4 1장 분량
- 진입 시 열람 로그 기록
- 하단 [퀴즈 응시하기] 버튼

### 3.5 응시 `/round/[no]/quiz`
문항 1개씩 순차 진행. 화면 구성:
1. 진행률 (3 / 12)
2. 남은 시간 (45초 카운트다운, 10초 이하 강조)
3. 문항 본문
4. 유형별 입력 영역
5. [제출] 버튼

제출 후 같은 화면에서 해설 단계로 전환:
1. 정답 / 오답 / 시간초과 결과
2. 정답
3. 해설 + 근거 조항
4. [다음 문항] 또는 [결과 보기]

**유형별 입력 UI (4종 모두 구현 필수)**

| 유형 | UI | 개수 |
|---|---|---|
| `OX` | O / X 큰 버튼 2개 | 14 |
| `MC4` | 선택지 4개 리스트, 단일 선택 | 55 |
| `ORDER` | **순서대로 탭하면 번호 배지가 붙는 방식.** 드래그 금지. 재탭으로 해제, [초기화] 제공 | 2 |
| `SHORT` | 텍스트 입력 1줄 | 1 |

### 3.6 회차 결과 `/round/[no]/result`
점수(n/12), 정답률, 문항별 정오 목록, 오답 문항 해설 다시 보기, 이번 회차 내 순위

### 3.7 복습 `/round/[no]/review`
종료된 회차의 문항·정답·해설 전체 열람. 읽기 전용, 점수 미반영.

### 3.8 대시보드 `/dashboard`
- 내 현황 카드: 내 누적 순위, 내 부서 순위 (순위권 밖이어도 항상 표시)
- 순위 4종 탭: 전체 누적 / 회차별 / 평균 / 부서
- 각 탭 기본 5행 + [더보기] → 20행
- 회차별 탭은 회차 선택 드롭다운 제공

### 3.9 내 기록 `/me`
회차별 점수 추이, 영역별 정답률, 사전학습 열람 여부

### 3.10 관리자 `/admin`
회차 개방 상태, 참여 현황, 회차별 통계, 문항 통계(P·D), 동일인 대조, 히트맵,
SHORT 미매칭 응답 조회, CSV 내려받기

관리자 화면은 **전부 읽기 전용**이다. 회차 개방 상태도 조회만 제공하고 전환 버튼은 두지 않는다
— 개방은 일정이 결정하고(business-rules 2절), 긴급 중단만 콘솔에서 수동 처리한다.

## 4. 예외 처리

| 상황 | 처리 |
|---|---|
| 새로고침 (응시 중) | 서버 상태 기준 현재 문항 재표시. `served_at` 유지 → 시간 계속 흐름 |
| 뒤로가기 | 이전 문항으로 못 돌아감. 현재 문항으로 리다이렉트 |
| 창 닫고 재접속 | 같은 세션 재개. 경과시간 그대로 |
| 네트워크 끊김 후 제출 | 서버가 45초 초과 판정 시 timeout |
| 중복 제출 | 이미 `answered_at`이 있으면 기존 결과 반환(멱등) |
| 개방 전/종료 후 접근 | 홈으로 리다이렉트 + 안내 |
| 미로그인 접근 | 로그인으로 리다이렉트 |
| 이미 완료한 회차 | 결과 화면으로 리다이렉트 |

## 5. 비기능 요건

| 항목 | 목표 |
|---|---|
| 동시접속 | 피크 100명 (월~금 5일 분산으로 부하 낮음) |
| 응답시간 | 문항 서빙·제출 300ms 이내 |
| 대시보드 | snapshot 조회로 100ms 이내 |
| 지원 환경 | 모바일 우선. iOS Safari / Android Chrome / 데스크톱 Edge·Chrome |
| 접근성 | 색상만으로 정보 전달 금지(정오 표시에 아이콘 병기) |
