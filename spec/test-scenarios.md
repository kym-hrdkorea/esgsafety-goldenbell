## M. 순위·관리자·사용성 잔여 개선 (T20)
| # | 시나리오 | 기대 |
|---|---|---|
| M1 | 3회차가 열렸지만 아직 마감되지 않음 | `fn_min_rounds()`가 0을 반환하고 순위표가 빈 상태로 전환되지 않음 |
| M2 | 실제 종료 회차가 3개가 됨 | `fn_min_rounds()`가 3을 반환하고 3회 이상 응시자만 순위 대상이 됨 |
| M3 | CSV 셀에 `=`, `+`, `-`, `@` 또는 앞 공백 뒤 수식이 포함됨 | Excel 수식으로 실행되지 않고 안전한 문자열로 내려받음 |
| M4 | CSV·SHORT 미매칭 데이터가 1,000행을 초과함 | 모든 행을 안정적인 순서로 조회하고 누락·중복이 없음 |
| M5 | 가입 검증 오류가 사번·닉네임·소속·PIN에 발생함 | 실제 오류 필드에 메시지가 표시되고 폼 전체 오류로 뭉개지지 않음 |
| M6 | 홈에 종료 회차와 개방 전 회차가 함께 있음 | 종료 회차는 “지난 회차”, 미개방 회차는 “예정 회차”로 분리됨 |
| M7 | 관리자 통계 요청이 네트워크 오류로 실패함 | 무한 스피너 대신 오류·재시도 상태가 표시됨 |
| M8 | 관리자 로그아웃 버튼을 누름 | 관리자 세션이 폐기되고 로그인 화면으로 이동함 |
| M9 | SHORT 답변 입력 중 Enter를 누름(IME 조합 중 포함) | 조합 중 Enter는 제출하지 않고, 조합이 끝난 Enter는 제출함 |
| M10 | ORDER 결과·복습 화면을 열람함 | 숫자 인덱스가 아니라 선택지 문구 순서가 표시됨 |
| M11 | 새 회차가 막 개방되어 아직 종료 회차가 없음 | 대시보드 기본 회차가 빈 새 회차보다 최신 종료 회차를 우선함 |
