### C1-02 · MC4 · L1

**직무와 관련해 100만원 이하의 금품을 받은 공직자등에게 적용되는 제재는?**

근거: 청탁금지법 §8②·§23⑤

### C1-09 · OX · L2

**배우자가 내 직무와 관련해 금품을 받은 사실을 알게 되면 나에게 신고 의무가 생긴다.**

- 정답: O

근거: 청탁금지법 §8④·§9①

### C1-10 · MC4 · L2

**훈련기관 관계자가 자리에 두고 간 상품권을 퇴근 무렵 발견했다. 가장 적절한 조치는?**

1. 돌려줄 방법이 마땅치 않으면 그대로 보관한다
2. 지체 없이 소속기관장에게 서면 신고하고 제공자에게 반환하거나 소속기관장에게 인도한다 **← 정답**
3. 부서 공동경비로 처리한다
4. 연말 정기 점검 때 일괄 보고한다

해설: 받을 의사가 없었더라도 신고와 반환이 원칙입니다. 제공자를 알 수 없거나 반환이 어려우면 소속기관장에게 인도하면 되고, 신고하지 않은 채 보관하는 것 자체가 위반입니다.

근거: 청탁금지법 §9①·②

### C1-11 · ORDER · L2

**부정청탁을 받았을 때의 처리 순서를 배열하시오.**

보기: 동일한 부정청탁을 다시 받음 / 부정청탁을 받았다는 사실을 인지 / 소속기관장에게 서면으로 신고 / 청탁한 사람에게 거절하는 의사를 명확히 표시 / 소속기관장이 직무 재배정 등 필요한 조치를 함
- 정답 순서: 부정청탁을 받았다는 사실을 인지 → 청탁한 사람에게 거절하는 의사를 명확히 표시 → 동일한 부정청탁을 다시 받음 → 소속기관장에게 서면으로 신고 → 소속기관장이 직무 재배정 등 필요한 조치를 함

해설: 최초 1회는 거절 의사를 분명히 밝히는 것으로 충분하고, 같은 청탁을 다시 받으면 그때는 반드시 서면 신고해야 합니다. 거절한 사실을 기록으로 남겨두면 나중에 본인을 보호합니다.

근거: 청탁금지법 §7①·②

### C1-12 · MC4 · L2

**다음 중 청탁금지법상 '부정청탁'에 해당하지 않는 것은?**

1. 자격시험 채점 기준을 특정 응시자에게 유리하게 바꿔 달라고 요구
2. 훈련기관 지정 요건을 법령과 다르게 완화해 처리해 달라고 요구
3. 자기 민원이 법정처리기한을 넘겼는지 진행 상황을 확인해 달라고 요구 **← 정답**
4. 감사 대상에서 특정 기관을 빼 달라고 요구

해설: 법정기한 내 처리 요청이나 진행 상황 확인은 법이 명시한 예외입니다. 공개적으로 요구하거나 법령·기준이 정한 절차에 따라 요구하는 것도 부정청탁이 아닙니다.

근거: 청탁금지법 §5②

### C1-13 · MC4 · L2

**국가기술자격 검정 업무와 관련해 부정청탁에 해당하는 것은?**

1. 응시 자격 요건을 법령대로 설명해 달라고 요청하는 것
2. 시험 일정과 장소를 공개된 절차에 따라 문의하는 것
3. 법령을 위반해 특정인이 시험위원으로 선정되거나 탈락하도록 영향을 미치는 것 **← 정답**
4. 채점 결과에 대해 정해진 이의신청 절차를 밟는 것

해설: 공공기관이 주관하는 시험·선발 위원 선정에 법령을 위반해 개입하는 것은 법이 열거한 부정청탁 유형입니다. 정해진 절차를 이용하는 요구는 부정청탁이 아닙니다.

근거: 청탁금지법 §5①

### C1-15 · MC4 · L2

**사례금을 받고 외부강의를 한 경우 소속기관장에게 신고해야 하는 기한은?**

1. 강의 요청을 받은 즉시
2. 강의를 시작하기 전까지
3. 강의를 마친 날부터 10일 이내 **← 정답**
4. 다음 달 말일까지

해설: 2020년 개정으로 사전 신고에서 사후 신고로 바뀌어, 마친 날부터 10일 이내에 서면으로 신고합니다. 사례금 총액을 미리 알 수 없으면 나머지를 먼저 신고하고 안 날부터 5일 이내에 보완합니다.

근거: 청탁금지법 §10②·시행령 §26

### C1-16 · MC4 · L3

**공직유관단체 임직원이 외부강의를 할 때 받을 수 있는 사례금 상한은?**

1. 직급과 무관하게 시간당 40만원, 1시간을 넘겨도 총 60만원 **← 정답**
2. 직급과 무관하게 시간당 100만원
3. 시간 제한 없이 회당 50만원
4. 상한 규정이 없다

해설: 공무원과 공직유관단체 임직원은 시간당 40만원이고, 1시간을 초과해도 총액은 그 150%인 60만원을 넘을 수 없습니다. 학교·언론사 등은 시간당 100만원으로 기준이 다릅니다.

근거: 청탁금지법 §10①·시행령 [별표 2]

### C1-17 · MC4 · L3

**외부강의 사례금을 상한액보다 많이 받은 사실을 알게 되었을 때의 조치는?**

1. 다음 강의 사례금에서 차감한다
2. 안 날부터 2일 이내에 소속기관장에게 서면 신고하고 초과액을 지체 없이 반환한다 **← 정답**
3. 연말정산 때 정산한다
4. 기관 공동경비로 납입한다

해설: 초과 사례금은 안 날부터 2일 이내 서면 신고와 지체 없는 반환이 원칙입니다. 신고와 반환을 모두 이행하면 제재 대상이 되지 않으므로 발견 즉시 처리하는 편이 유리합니다.

근거: 청탁금지법 §10

### C1-19 · MC4 · L1

**공직자의 이해충돌 방지법이 정한 10가지 행위기준의 구성으로 옳은 것은?**

1. 신고·제출 의무 5가지 + 제한·금지 행위 5가지 **← 정답**

### C1-20 · MC4 · L2

**직무관련자가 사적이해관계자임을 알게 된 공직자가 해야 할 조치는?**

### C1-21 · MC4 · L3
