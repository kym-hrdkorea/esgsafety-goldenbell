# Claude Design 전달 프롬프트

> 첨부 파일: `design/design-brief.md`, `design/copy.md`, `design/screens.md`

---

첨부한 3개 문서를 기준으로 모바일 우선 웹앱 UI 시안을 만들어 주세요.

한국산업인력공단 내부 직원 약 1,800명이 8주간 매주 참여하는 **안전 퀴즈 리그**입니다.
슬로건은 "안전 이룸, 함께 해냄"입니다.

**가장 중요한 제약**: 이 캠페인은 직원들이 "안전은 재미없고 나와 관계없다"고 느끼는 문제를 풀기 위한 것입니다. 공공기관 시스템처럼 보이면 1주차에 이탈합니다. 동시에 안전이라는 주제의 진지함은 유지해야 합니다.

## 우선 제작 순서
1. **응시 화면 — 답변 단계** (4지선다)
2. **응시 화면 — 해설 단계** (정답 / 오답 / 시간초과 3가지 상태 모두)
3. **대시보드** (내 현황 카드 + 순위 4종 탭 + 5행 표시/더보기)
4. **홈**

## 반드시 지켜 주세요
- `design/copy.md`의 한국어 문안을 **그대로** 사용. lorem ipsum 금지
- 문항·선택지·해설은 브리프에 적힌 **가장 긴 실제 예시**로 렌더링해 레이아웃 검증
- 진행률(12문항 중 n번째), 45초 카운트다운, 정오 피드백 — 이 3가지를 시각적으로 강하게
- 정오는 색상만이 아니라 **아이콘을 병기**
- 터치 타겟 최소 48px, 하단 고정 CTA
- 다크모드·브라우저 스토리지 불필요

## 문항 유형 4종 모두 시안이 필요합니다
OX(큰 버튼 2개) / 4지선다(카드 4개) / 순서배열(**탭하면 번호 배지가 붙는 방식**, 드래그 아님) / 단답(1줄 입력)

먼저 응시 화면 답변 단계부터 만들고, 방향을 확인한 뒤 나머지로 넘어가 주세요.
